Quick Start

  1. Clone Repository:
    git clone https://github.com/mdeepakreddy456/Store_Intelligence.git
  2. Start Services:
    docker compose up --build
  3. Run Detection:
    python pipeline/detect.py
  4. Access API:
    http://localhost:8000/docs
  5. Launch Dashboard:
    python dashboard/live_dashboard.py

API Endpoints

  • GET /health - Service health check
  • GET /stores/{store_id}/metrics - Store metrics
  • GET /stores/{store_id}/funnel - Visitor funnel
  • GET /stores/{store_id}/heatmap - Zone heatmap
  • GET /stores/{store_id}/anomalies - Operational anomalies
  • POST /events/ingest - Ingest events
